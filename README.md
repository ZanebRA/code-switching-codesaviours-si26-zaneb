# Code Switching NLP | Code Saviours SI-26 | Zaneb Rasool Ahmed

## Project Overview
This project focuses on creating a Roman Urdu and English code-switching dataset for Natural Language Processing (NLP). The dataset contains naturally mixed-language sentences collected from public online sources and manually labeled for language identification.

## Objective
To build a high-quality code-switching dataset that can be used to train and evaluate NLP models capable of understanding mixed Roman Urdu and English text.

## Dataset Labels
- **URD** – Roman Urdu word
- **ENG** – English word
- **MIX** – Mixed or ambiguous word
